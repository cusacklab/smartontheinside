## Directories

**`manuscript/`** — current figures, regenerated from the analyses in
`data/results/`. Each is reproducible from the command in the tables above.

**`upstream_docker_hcp/`** — Figs. S3 and S4 come from the contrast-selection
stage, which lives in a **separate `docker-hcp` repository**, not here. The
original README names `roi_extract_one_subject.py`, `hcp_example.py` and
`MeanSTD.py` as the code. Rendered copies were recovered from
`s3://foundcog/backups-2026-01-27/home/chiaracaldinelli/docker-hcp/`, where that
repository is also backed up in full. They are kept here for reference only and
are **not** regenerated by anything in this repository.

**`superseded/`** — the figures that were in the repository root before the 2026
restructure (`matrix_*.png`). They were produced by `legacy/classifier_check_res.py`
from the 183-neonate analysis and are **superseded** by the `neonatal_N325_*`
figures. Kept for comparison with the current manuscript draft; do not reuse.

## Fig. S5 has no code

No script in this repository, in `legacy/`, or found by searching for
ANOVA/parcel-profile code produces the per-parcel activation profiles. It needs
the adult activation arrays averaged within each of the 26 DLPFC parcels — the
data for which is now available (`data/derivatives/act_for_classifier_*` plus the
parcel definitions in `data/results/table_S1_dlpfc_parcels.tsv`), so it can be
written if the figure is being kept.
